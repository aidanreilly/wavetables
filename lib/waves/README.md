# Wavetables

The three banks in this directory are the ROM wavetable banks of the
Synthesis Technology E350 Morphing Terrarium.

<https://synthtech.com/eurorack/E350/>

Each file holds 64 single-cycle waveforms of 256 samples, stored
end-to-end as mono 16-bit 44.1 kHz WAV. That is the standard WaveEdit
bank format, and these were exported with WaveEdit.

| File | Bank |
|---|---|
| `rom_a.wav` | ROM A |
| `rom_b.wav` | ROM B |
| `rom_c.wav` | ROM C |

The banks are the work of Synthesis Technology and are included here so
the script runs without a separate download. All credit for the
waveforms belongs to them.
